# Third-party assets

This file records the source and license of assets that are not original to
this repository. The game must not depend on downloading these files at
runtime; reviewed copies live under `assets/` and are bundled by Flutter.

## Sound effects

The following OGG files were downloaded from Kenney's official website on
2026-09-11. Both source packs are released under CC0 1.0.

| Bundled file | Kenney pack | Original file |
| --- | --- | --- |
| `purchase.ogg` | RPG Audio | `handleCoins.ogg` |
| `refresh.ogg` | UI Audio | `switch17.ogg` |
| `ready.ogg` | UI Audio | `click2.ogg` |

Source pages:

- https://kenney.nl/assets/rpg-audio
- https://kenney.nl/assets/ui-audio
- License: https://creativecommons.org/publicdomain/zero/1.0/

Downloaded archives were inspected before extraction. They contained only
`.ogg`, `.txt`, and `.url` entries; no executable or script files were copied
into the project.
