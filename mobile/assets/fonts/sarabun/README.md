# Launch font

Sarabun Medium (500) and Bold (700), distributed under SIL Open Font License 1.1.
The accompanying OFL.txt is the original license and copyright notice.

Source: https://github.com/google/fonts/tree/main/ofl/sarabun

Flutter registers these files as `LaunchSarabun` in pubspec.yaml. The HTML
bootstrap uses the same files at `assets/assets/fonts/sarabun/` in Flutter web's
asset bundle. Keep both splash implementations at zero letter spacing for Thai.
This family is scoped to launch screens; it does not change the game UI font.
