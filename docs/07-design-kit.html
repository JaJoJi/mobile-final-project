TECHNIQUE 01

ยุบสิ่งที่ไม่ได้กำลังสั่งการ

TFT รวม stage/round/timer เหลือแถบเดียว แทนที่จะกางทุกอย่างพร้อมกัน — ที่นี่คู่แข่งยุบเหลือแถบ scout ตอนวางแผน

TECHNIQUE 02

สถานะเป็นแสง ไม่ใช่ป้าย

Auto Chess Mobile ใช้แอนิเมชันพื้นหลังบอกว่า “มีอยู่แล้ว/อัปได้” แทนตัวหนังสือ — ที่นี่คือแหวนทองรอบการ์ด

TECHNIQUE 03

รายละเอียดอยู่หลังการกระทำ

ไอคอนสกิล/trait ของ TFT เรียบตอนย่อ เต็มตอนกดดู — ช่องบอร์ดที่นี่โชว์แค่รูปทรง+ดาว กดค้างเพื่อดูสเตตัส

TECHNIQUE 04

งบพื้นที่แนวตั้งมีจำกัด

มือถือบังคับ layout แนวตั้ง+โซนนิ้ว — ทุกพื้นที่ที่ยุบได้ (คู่แข่ง, ม้านั่ง) ต้องยุบ ก่อนกระดานที่ใหญ่ขึ้นจะไม่พอจอ

06 — กฎที่ reviewer เช็ก

ห้าข้อที่ทำให้ PR ตก

รายการเต็มอยู่ใน §9.2 ของสเปก ห้าข้อนี้คือที่พลาดบ่อยสุดตอนเขียนหน้าเกม

PR CHECKLIST
01 · NO MAGIC NUMBERS

ห้าม Colors.* · fontSize: · padding นอกสเกล 4dp · Duration() ดิบ ใน features/** ทุกค่าดึงจาก token

02 · เวลาต้องไม่โกหก

นับถอยหลังจาก deadline ที่คำนวณจาก server เสมอ ห้าม Timer.periodic ลบวินาทีเอง และคำนวณใหม่ทุกครั้งที่แอปกลับจาก background

03 · เดาได้เฉพาะที่อนุญาต

optimistic ได้แค่ ซื้อ/ขาย/รีเฟรช/รวม/วาง/พร้อม + ต้อง rollback ได้ ห้ามเดาผลการต่อสู้หรือดาเมจ เด็ดขาด

04 · สีอย่างเดียวไม่พอ

ฝ่าย · ระดับเลือด · แพ้ชนะ ต้องมี รูปทรง ไอคอน หรือตำแหน่ง กำกับเสมอ และมีทางเลือกแตะวางแทนการลาก

05 · สี่สถานะทุกหน้า

loading เป็น skeleton ตามรูปทรงจริง · empty มีทางไปต่อ · error มีทางออก · ปุ่ม submit กันกดซ้ำและบอกเหตุผลตอน disabled
